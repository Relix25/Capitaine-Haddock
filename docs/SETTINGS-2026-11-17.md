# Formulaire de réglages Discord — 17 novembre 2026

`/settings` remplace `/modele` et ouvre directement un modal Discord à deux listes déroulantes : modèle (Tencent HY4 Flash ou DeepSeek V4.1 Flash) et mode debug (activé ou désactivé). Les valeurs actuelles sont présélectionnées. La validation enregistre les deux réglages ; fermer le modal ne change rien. Le formulaire expire après cinq minutes et peut être rouvert pour modifier les réglages.

Le debug correspond aux statistiques sous les réponses du chatbot : modèle, TTFT, durée IA, TPS estimés et tokens. Désactivé, il supprime le sous-texte des réponses textuelles et le message de statistiques associé aux samples vocaux. Le compteur du quota et les mesures techniques continuent de fonctionner ; aucune conversation n'est persistée. Le debug reste activé pour les installations existantes qui n'ont pas encore enregistré de préférence.

Le modal est réservé à son auteur, administrateur avec le rôle requis dans le salon/serveur configurés. Ces contrôles sont répétés à la validation, pour tenir compte d'un retrait de rôle ou de permission pendant que le formulaire est ouvert. Les confirmations et erreurs sont éphémères, sans mention. Aucun texte d'interaction ni exception contenant des données privées n'est journalisé.

Le choix du modèle et le booléen `debug` sont écrits atomiquement dans `/var/lib/cours-watch/model-selection.json`, droits 0600. Les anciens fichiers contenant uniquement `selection` restent lisibles. Un échec d'écriture conserve les réglages actifs. La modification attend la fin d'une génération en cours et préserve le compteur, le plafond de 10 millions et la mémoire courte. Les règles ZDR des profils ne changent pas : exigé pour DeepSeek, non exigé pour HY4, avec `store: false` dans les deux cas.

L'enregistrement crée d'abord `/settings`, puis retire seulement les anciennes commandes slash `modele`/`modèle` du serveur configuré. Les autres commandes de l'application sont préservées. Le modal utilise les composants Label et String Select disponibles dans discord.py 2.7.1 et décrits par la [documentation Discord](https://docs.discord.com/developers/components/using-modal-components).

Sur le VPS, le vrai callback `/settings` a ouvert le modal sur un adaptateur d'interaction.
